# 信号处理模块

所有物理信号均以16位有符号整数表示，范围为-32768至32767，实际大小及单位和板卡输出振幅挂钩。

参数设定格式：
<模块变量名>.write(<地址/参数名>, <值>)

```python
pid = module.ModulePID(bus_inst, "PIDC")
pid.write(0, 16384)
pid.write("gain_p", 16384)  
pid.write("saturation_gain", 10) # 10dB
```

参数读取格式：
<模块变量名>.read(<地址/参数名>)

```python
...
pid.read("gain_p") # 16384
pid.read("saturation_gain") # 10
```

部分间接参数在读取时可能返回无穷大np.inf。

### 直接参数

|地址|参数名|位宽|范围|含义|备注|
|----|----|----|----|----|----|
|0|gain_p|24|-2^23 ~ 2^23-1|P通道增益系数|线性增益系数。取对数后才可转换为分贝值。可通过间接参数直接设定分贝值|
|1|gain_i|32|-2^31 ~ 2^31-1|I通道增益系数|同上|
|2|gain_d|24|-2^23 ~ 2^23-1|D通道增益系数|同上|
|3|setpoint|16|-32768 ~ 32767|设定值|物理信号|
|4|limit_integral|16|0 ~ 32767|积分限幅值|物理信号|
|5|limit_sum|16|0~ 32767|输出限幅值|物理信号|
|6|leak_digit|32|无效|积分泄漏控制参数|仅推荐通过间接参数修改

### 间接参数

|参数名|范围|含义|备注|
|----|----|----|----|
|overall_gain|实数，单位为dB|整体增益|调节P通道增益，并等比例缩放I、D通道增益。若缩放后任一通道增益超出范围则报错。若初始P通道增益为0（缩放比例为无穷大），则仅调节P通道增益|
|pi_corner|非负实数，单位为Hz|PI交点频率|调节I通道增益。使得PI增益曲线交点位于指定频率。若调节后I通道增益超出范围则报错|
|pd_corner|非负实数，单位为Hz|PD交点频率|调节D通道增益。使得PD增益曲线交点位于指定频率。若调节后D通道增益超出范围则报错|
|saturation_gain|实数，单位为dB|饱和增益|调节泄漏系数，使得积分通道在设定增益处饱和。若饱和增益过大，则设定为无饱和。若饱和增益过小，则设定为最大泄漏。若I通道增益为0，则报错|
|saturation_turning_frequency|非负实数，单位为Hz|饱和拐点频率|调节泄漏系数，使得积分通道在设定频率处饱和。若饱和频率过小或为0，则设定为无饱和。若饱和频率过大，则设定为最大泄漏|

### 可视化

在自由模式下，允许用户调整除了leak_digit以外的所有直接和间接参数。

绘制PID控制器的增益曲线：
- 一个坐标系，横坐标为对数频率（Hz），纵坐标为增益（dB）。
- 根据overall_gain绘制比例通道的响应，斜率为0，截距即为overall_gain。
- 根据pi_corner绘制积分通道的响应，斜率为-20dB/十倍频程，在pi_corner处与比例通道响应曲线相交。
- 根据pd_corner绘制微分通道的响应，斜率为+20dB/十倍频程，在pd_corner处与比例通道响应曲线相交。
- 根据saturation_turning_frequency绘制积分饱和响应，斜率为0，在saturation_turning_frequency处与积分通道响应曲线相交。
- 用户可以通过调整参数，观察增益曲线的变化。
- 注意根据gain_p、gain_i、gain_d的实际值，上述参数可能出现0或者无穷大的特殊情况，绘图时需要进行相应处理。

## pdh状态机
这是一个用于 **PDH** 激光稳频技术的 VHDL 状态机模块。

这个模块的主要功能是自动或手动地完成“扫描（Scanning）”到“锁定（Locking）”的过程。它通过检测输入信号，控制 PID 控制器、混频器和扫描锯齿波的使能状态。

下面我将详细解释各个参数以及状态机各个状态的作用。


### 1. 端口与参数详解

#### **输入/输出端口 (Ports)**
*   **`core_param_in` (256-bit)**: 核心配置总线，包含来自上位机的所有控制参数。
*   **`sig_in`**: 关键输入信号。在 PDH 系统中，这通常是光电探测器检测到的透射光强。状态机根据这个信号的大小来判断是否找到了共振峰。
*   **`pid_enable`,`mixer_enable`**,**`sawtooth_enable`**: 控制pid控制、混频器和扫描锯齿波的使能的信号。在'0' 表示开启功能，'1' 表示关闭或旁路。
*   **`saw_input`**: 输入的锯齿波信号，用于状态机同步。状态机需要知道当前扫描周期的相位，以便在周期的特定时刻开始测量。

#### **解析 `core_param_in` 参数 (从总线解包)**

代码开头将 256 位的总线拆分为具体的控制变量，地址分配如下：

1.  **`pc_cmd` (0x00, bits 1:0)**: **控制命令**。
    *   `"00"`: IDLE (空闲/复位)。
    *   `"01"`: 手动触发扫描锁定流程。
    *   `"10"`: 自动触发扫描锁定流程（包含自动测量阈值）。
    *   `"11"`: 在锁定状态下用于中止或确认。

2.  **`threshold_signal_locking` (0x01, bits 47:32)**: **手动锁定阈值**。
    *   在手动模式的 `LOCKING` 状态下使用。当信号低于此值时，认为锁定保持成功；否则可能认为失锁。

3.  **`threshold_signal_scanning` (0x02, bits 79:64)**: **手动扫描阈值**。
    *   在手动模式的 `SCANNING` 状态下使用。当输入信号低于此值（通常是找到吸收峰或误差信号过零点附近）时，开始计时准备锁定。

4.  **`time_duration_scanning` (0x03, bits 127:96)**: **手动扫描持续时间**。
    *   信号必须在“扫描阈值”范围内保持这么长时间，状态机才会判定找到了共振峰，并跳转到锁定状态。这用于防止噪声误触发。

5.  **`time_duration_locking` (0x04, bits 159:128)**: **手动锁定保持时间**。
    *   进入锁定状态后，如果信号满足锁定条件，会计数该时间。通常用于看门狗功能，或者测试锁定是否能维持特定时长。

6.  **`coef_scan` (0x05, bits 175:160)**: **自动模式扫描系数** (Q1.15 格式)。
    *   用于计算自动扫描阈值。
    *   公式：`Auto_Threshold = Min + (Max - Min) * coef_scan`。
    *   这意味着阈值是根据信号峰峰值的相对比例设定的（例如设置在波谷上方 20% 处）。

7.  **`coef_lock` (0x06, bits 207:192)**: **自动模式锁定系数**。
    *   类似上者，用于计算自动锁定判定阈值。

---

### 2. 内部计算逻辑

在进入状态机之前，代码有一段数据处理逻辑，专门为**自动模式**服务：

1.  **`diff_sig_in`**: 计算输入信号的峰峰值 (`max_sig_in - min_sig_in`)。
2.  **`scaled_scan_sig_in`**: 将峰峰值乘以系数 `coef_scan`。
3.  **`auto_threshold_signal_scanning`**: 动态计算出的阈值。

### 3. 状态机详解 (FSM)

状态机分为**手动模式**路径和**自动模式**路径。

#### **公共/基础逻辑**
*   **锯齿波跳变检测 (`sawtooth_jump`)**: 检测 `saw_input` 的最高位翻转。这标志着一个扫描周期的结束和下一个周期的开始。所有的自动测量步骤都依赖这个信号来同步，确保测量是在一个完整的扫描周期内进行的。
*   **Reset**: 复位时回到 `IDLE`，并将 PID、Mixer、Sawtooth 全部置为 '1'（禁用/默认状态）。

#### **状态 1: `IDLE` (空闲)**
*   **作用**: 等待命令。
*   **输出**: 所有输出禁用 (`1`)。
*   **跳转**:
    *   收到 `pc_cmd = "01"` -> 进入 **手动模式** (`SCANNING`)。
    *   收到 `pc_cmd = "10"` -> 进入 **自动模式** (`AUTO_WAIT`)。

---

#### **路径 A：自动模式 (Auto Mode)**
此模式旨在自动测量信号特征，计算阈值，然后锁定。

*   **状态 2: `AUTO_WAIT` (等待同步)**
    *   **作用**: 等待下一个锯齿波周期的开始，以确保后续测量覆盖完整的周期。
    *   **动作**: 开启扫描 (`sawtooth_enable <= '0'`)。
    *   **跳转**: 检测到 `sawtooth_jump` 后，初始化 Min/Max 寄存器，跳转到 `AUTO_AMP`。

*   **状态 3: `AUTO_AMP` (自动幅度测量)**
    *   **作用**: 在整整一个扫描周期内，持续捕捉输入信号 `sig_in` 的最大值和最小值。
    *   **计算**: 更新 `min_sig_in` 和 `max_sig_in`。
    *   **跳转**: 扫描周期结束 (`sawtooth_jump`) 后，跳转到 `AUTO_TIME`。此时，硬件电路部分的动态阈值计算逻辑会自动根据刚才测得的 Min/Max 更新阈值。

*   **状态 4: `AUTO_TIME` (自动时间宽度测量)**
    *   **作用**: 测量共振峰的“宽度”。
    *   **逻辑**: 统计信号低于 `auto_threshold_signal_scanning`（自动计算出的阈值）的时间长度。
    *   **目的**: 确定共振峰在时间轴上的宽度，从而自动设定“去抖动时间”。如果信号只是瞬间穿过阈值（噪声），不算共振；必须保持一定宽度。
    *   **结果**: 计算出 `auto_time_duration_scanning` (宽度的一半) 和 `auto_time_duration_locking` (宽度的4倍)。
    *   **跳转**: 周期结束且测量有效后，跳转到 `AUTO_SCANNING`。

*   **状态 5: `AUTO_SCANNING` (自动扫描中)**
    *   **作用**: 实际执行寻找共振峰的过程。
    *   **输出**: `mixer_enable <= '0'`, `pid_enable <= '1'` (PID 仍禁用，但在扫描)，`sawtooth_enable <= '0'` (扫描开启)。
    *   **逻辑**:
        *   如果 `sig_in < auto_threshold_signal_scanning`（进入共振区）。
        *   **且** 保持时间超过了 `auto_time_duration_scanning`（确认是共振峰，不是噪声）。
    *   **跳转**: 满足上述条件，说明正好处于共振峰中心附近，立即跳转到 `AUTO_LOCKING`。

*   **状态 6: `AUTO_LOCKING` (自动锁定中)**
    *   **作用**: 切断扫描，接通 PID，维持锁定。
    *   **输出**: `pid_enable <= '0'` (PID 激活!), `sawtooth_enable <= '1'` (扫描停止/保持)。
    *   **逻辑**:
        *   监控信号是否维持在 `auto_threshold_signal_locking` 之上（检查是否失锁）。
        *   如果失锁或超时，并且收到 `pc_cmd="11"`，则返回 `IDLE`。这个参数用于在测试时将状态机强制禁止退出`AUTO_LOCKING`状态。

---

#### **路径 B：手动模式 (Manual Mode)**
此模式使用 PC 预设的固定阈值和时间参数。

*   **状态 7: `SCANNING` (手动扫描)**
    *   **作用**: 寻找共振点。
    *   **输出**: 扫描开启，PID 禁用。
    *   **逻辑**:
        *   对比 `sig_in` 和固定参数 `threshold_signal_scanning`。
        *   如果满足条件并持续 `time_duration_scanning` 时间。
    *   **跳转**: 满足条件则跳转到 `LOCKING`。

*   **状态 8: `LOCKING` (手动锁定)**
    *   **作用**: 激活 PID 闭环。
    *   **输出**: PID 激活 (`0`)，扫描停止 (`1`)。
    *   **逻辑**:
        *   检查信号是否满足 `threshold_signal_locking`。
        *   如果一直满足，计数器 `time_able` 会累加。
        *   **注意**: 代码中 `if time_able < time_duration_locking ... else current_state <= IDLE`。这意味着在手动模式下，它似乎只是“试锁定”一段时间。如果超过了设定的锁定持续时间，它会自动回到 IDLE（或者是设计为看门狗超时复位）。这取决于具体的应用场景，有时是为了测试锁定稳定性。

# 封装后模块

由一个或多个基础模块封装而成。

端口连接格式：
router.set_routing(目标端口名, 源端口名)
router.upload()

```python
router.set_routing("TRI_IN", "ACC_OUT")
router.set_routing("OUTPUT_A", "TRI_SIN")
router.upload() # 一次同时上传所有连接设定
```

特殊端口：
- VOID：通往该端口的16bit物理信号被忽略，来自该端口的信号恒为0，用于表示“断开”状态。
- VOID_BOOL：同上，但适用于布尔信号。
- LOW：来自该端口的布尔信号恒为0。
- HIGH：来自该端口的布尔信号恒为1。

累加器：
- 外部反馈输入：模块外部频率调制
- 自动开关指令：模块自动开关指令
- 暂停累加指令：连接至LOW
- 累加值输出：连接至第一个三角函数运算器的相位信号输入
- 快变累加值输出：连接至第二个三角函数运算器的相位信号输入

三角函数运算器1：
- 相位信号输入：连接至累加器累加值输出
- 正弦信号输出：模块正弦信号输出
- 余弦信号输出：模块余弦信号输出

三角函数运算器2：
- 相位信号输入：连接至累加器快变累加值输出
- 正弦信号输出：模块倍频正弦信号输出
- 余弦信号输出：模块倍频余弦信号输出

### 可用参数

累加器：
- freq
- enable_auto_reset
- ratio

### 初始化

调用各内部模块初始化函数，断开所有外部端口连接。
累加器的bypass_lf设定为0。
